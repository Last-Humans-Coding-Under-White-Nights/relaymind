# Pinned source-grounded development version 2

Use [the runnable guide](../../../docs/SOURCE_BENCHMARK.md) to acquire originals,
build the catalog and ordinary product metadata imports, prepare a team index,
and run builtin/external selectors against the same full catalog and cases.

- `sources.v2.json`: 442 pinned files, 445 retained original candidates and 28
  predeclared exclusions; the bounded builder produces 412 assets and 61 exclusions.
  It records exact URLs, revisions, lengths, hashes and applicable source evidence.
  Raw captures and unknown-license skill bodies remain outside this repository.
- `cases.v2.json`: 128 author-defined source references frozen before these runs:
  116 positives, six ambiguous and six unsupported cases; 59 Chinese, 59 English and
  ten mixed queries; 54 capability intents and 58 distinct target assets.
- `measurements.v2.json`: compact internal diagnostics for eight actual CLI arms
  and six comparisons. Full local reports retain original metadata and are not
  redistributed here. The summary records their hashes and actual observations.
- `comparison-reassessment.v2.json`: corrected offline classification of the
  same preserved reports. Four builtin-to-stateless/cold pairs are compatible;
  two cold-to-reuse pairs are incompatible because preparation profiles differ.
  The original six comparison artifacts and `measurements.v2.json` remain
  historical evidence, with their original bytes and hashes unchanged. No
  measured arm, reference or budget was rerun or retuned for this correction.

The 58 targets comprise 37 skills and 21 MCP tools. All 412 catalog assets are offered
for every case, including functional decoys. Case variants do not become
independent people or independent human judgments. Reference notes describe
uncertainty; ambiguous cases retain multiple actual alternatives and no real user
choices are manufactured. Original/description languages use the declared text
heuristic; no native-author proof is inferred. The catalog has no Chinese or mixed
MCP descriptions, so those language pairs remain absent rather than being padded.

The source-derived catalog contains 87 Matrix skills (65 Chinese/22 English bodies;
57 Chinese/30 English descriptions), 194 English SkillsBench skills and 131 genuine
English GitHub MCP tool descriptions. The 61 exclusions include prohibited upstream
retention, package-name inconsistencies, safe archive limits, missing/duplicate
archive paths, unsupported tool definitions and duplicate original identities.
Exact reason counts are in the measurement summary. Rights and availability stay
unknown unless supported by separately reviewed evidence.

The Chinese memory-leak request targets an original English Matrix skill. It was
not edited to hide the lexical baseline's observed miss. The earlier 47-asset/36-case
version remains immutable in the retained capture record; version 2 broadens the
catalog and references instead of rewriting that result. None of these artifacts
claims independent formal 200/300 qualification, a native platform pass or an
algorithm quality gate. Users may import arbitrary supported skill sources.
